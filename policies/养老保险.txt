【李营村城乡居民基本养老保险政策】（2025-2026年）

一、参保条件
年满16周岁（不含在校学生），未参加城镇职工基本养老保险的本村户籍居民，均可自愿参保。

二、缴费档次与政府补贴（每年）
共设15个档次，当年缴费享受政府补贴，补缴往年不享受补贴：
1. 年缴200元，政府补贴30元
2. 年缴300元，政府补贴40元
3. 年缴400元，政府补贴50元
4. 年缴500元，政府补贴60元
5. 年缴600元，政府补贴80元
6. 年缴700元，政府补贴100元
7. 年缴800元，政府补贴120元
8. 年缴900元，政府补贴140元
9. 年缴1000元，政府补贴160元
10. 年缴1500元，政府补贴190元
11. 年缴2000元，政府补贴220元
12. 年缴2500元，政府补贴250元
13. 年缴3000元，政府补贴280元
14. 年缴4000元，政府补贴310元
15. 年缴5000元，政府补贴340元
建议有条件的村民选择较高档次缴费，多缴多得。

三、养老金领取条件
1. 年满60周岁
2. 累计缴费满15年（不足15年的可一次性补缴，但补缴部分不享受政府补贴）
3. 未领取国家规定的其他基本养老保障待遇
4. 制度实施时已满60周岁的，可直接领取基础养老金，无需缴费

四、养老金计算
月养老金 = 基础养老金 + 个人账户养老金
1. 基础养老金：全省最低标准约185元/月（2026年标准），70-79岁每月加发10元，80岁以上再加20元
2. 个人账户养老金 = （个人缴费总额 + 政府补贴总额 + 利息）÷ 139
3. 缴费年限超过15年的，每多缴1年，每月增发3元基础养老金
4. 养老金终身发放，人活着就一直领

五、待遇测算（按缴费15年，基础养老金185元/月测算）
1. 年缴200元：月领约213元
2. 年缴500元：月领约245元
3. 年缴1000元：月领约300元
4. 年缴2000元：月领约411元
5. 年缴5000元：月领约745元

六、特殊政策
1. 低保对象、特困人员等困难群体，由地方政府代缴最低档次保费
2. 重度残疾人参保，政府额外补贴100元/年
3. 参保人员死亡的，个人账户余额可依法继承，并发放丧葬补助金

七、办理流程
1. 新参保：携带身份证、户口本到村委会填写参保登记表
2. 选择缴费档次，每年1月-12月通过线上或线下渠道缴费
3. 满60周岁前3个月，到村委会办理待遇申领手续
4. 养老金通过社保卡按月发放

八、缴费渠道
1. "河南税务"微信公众号/支付宝小程序
2. "豫事办"APP
3. 村委会代办
4. 各商业银行网点

九、重要提醒
1. 当年缴费才有政府补贴，补缴往年不享受补贴
2. 建议尽早参保、连续缴费、选择较高档次
3. 个人账户的钱永远属于参保人，没领完的部分可由继承人全额继承
